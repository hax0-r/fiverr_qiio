End-to-end IoT solution

An end-to-end IoT solution is ideal for customers because they only work with one partner. In this article, we will introduce what the key elements are in a good IoT solution.

End-to-end & Secure
When companies want to have business and process tools, the majority buys a solution of SAP. The reason is that SAP provides an agnostic solution to all types of businesses. qiio, in the world of IoT, also provides the same thing: an agnostic solution for all businesses.

What qiio offers for IoT is an end-to-end solution covering hardware, software, cloud services, and operation. Customers will receive a full-package solution directly from qiio and do not have to deal with different partners and service providers. They get one partner and one solution, where hard- and software go hand in hand seamlessly.

95/5 blueprint & modularity
qiio IoT solution is completely modular. We call it: 95/5 blueprint. It means that in every new customer project, 95% of the solution is ready to go and only 5% needs to be customized to match specific needs.

95/5 blueprint provides modularity that enables two things: fast integration, and adaptability.

Our closest competitor will need 6 months to achieve what we can do in one week. This is not even comparing apples to apples. The closest competitor misses important parts of the puzzle to develop an end-to-end IoT solution. Moreover, we can adapt our solution for different use cases and markets because of modularity.

Key elements in an end-to-end IoT solution
When diving deeply into the world of IoT, one might easily find that different knowledge is required to build a solution. Key elements are:


Interface between the data source and the IoT hardware
IoT hardware
Transmission channel
Internet connection
Cloud backed
Cloud front end
Data visualization on enterprise resource planning (ERP) systems.
The development of an IoT solution is complicated. That is why many solution providers only support either hardware development or cloud portal. We provide every building block for our customers.

qiio hardware: flexible & ready for mass production
We offer industrialized hardware that is ready for mass production. Customers can choose between three types of hardware with different performance.

qiio IoT hardware, Concentrator, is an integrated hardware chip with 30x50mm size. The qiio hardware enables to connect a data source, such as a coffee machine, to the cloud.

Functioning more than a gateway, the qiio hardware also supports data acquisition and data processing. Every qiio hardware is equipped with an embedded SIM card per default. Customers have cost-attractive cellular connectivity worldwide thanks to more than 700 roaming partners. In addition, a user can manage and monitor connectivity through connectivity management, one of the cloud services provided by qiio.

Worldwide, qiio Concentrator Sphere is the first plug-and-play IoT solution based on a security MCU developed by Microsoft. qiio Concentrator Sphere is pin compatible with all other qiio Concentrator. As a result, it brings seamless integration of Azure Sphere in qiio product portfolio.

qiio software & cloud services
Customers can easily manage service infrastructure. The cloud services include:

Device management
Application management
Connectivity management
User management

Device management
Device management allows users to remotely conduct security updates and machine configuration. In addition, a user can also monitor and track a device through qiio device management. If a device does not operate, a user is able to view the diagnostic reports. There is no need to physically present at the machine to receive data.

Application management
Most of our customers connect their machines online. Sometimes, machine control software will change and the machines require updates. Application management enables our customers to finish update over the air.

Connectivity management
Even though qiio hardware supports various connectivity technology, our customers very often choose cellular connectivity for their solution. Connectivity management is designed for cellular data monitor and configuration. Moreover, customers can also check if their machines are properly connected to the cloud in order to conduct remote updates.

User management
An IoT solution can provide different information to different audiences. Therefore, it is important to set permission properly. User management enables a company to set roles and permission.

Data access & visualization
With all cloud services, our customers can fully manage their machines. Customers can access device data and cloud services through REST API. qiio provides a management portal on top of the REST API. The portal enables a throughout and quick start in using qiio cloud services. On the portal, we will provide data analysis and data visualization.

Customers can also define an endpoint for data. Afterward, customers can use own ERP systems for further data processing.

Security
Security is important for any IoT solution. qiio follows the seven properties of highly secured devices for IoT devices, which includes:

Hardware-based root of trust
Small trusted computing base
Defense in depth
Compartmentalization
Certificate-based authentication
Renewable security
Failure reporting
In addition, the result of external security audits shows that our solution is secure and robust.
